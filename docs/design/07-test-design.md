### 1.2 How mocks are used

- **AI adapters.** `AI_*` settings choose `mock` in all automated tests except
  `SPIKE` and `SAFE-L`. `MockAdapter` loads fixtures by `fixture_key`
  (upload filename without extension) and supports scripted behaviors:
  the fault kinds of `04` section 8.1: `transient` (raises `AiTransientError`),
  `invalid_output` (raises `AiInvalidOutput` as if the adapter's one schema
  retry had also failed), and `permanent` (raises `AiPermanentError`), each
  with `fail_times` counted per fixture, then success. A fixture file is
  `{AI_MOCK_FIXTURES_DIR}/{fixture_key}.json` and falls back to `default.json`.
  The mock reports `usd_micros=0`. The "invalid once, then valid" path inside
  the adapter is a unit test of the real adapter wrapper with a fake HTTP
  client (`UT-AI-02`), not a mock fault. Scripts run through the real
  `CostService` and the real `JobRunner`, so retry and ledger rules are
  tested as written. A `CallCounter` fixture counts provider calls and ledger
  rows. Terms used below: `JobError(code, retryable)` (plus optional
  `retry_after_s`) is the only handler error (`06` `app/errors.py`, `04` section
  8.8); `code` is the stored fail code.
- **ffmpeg.** `UT` and `API` levels never run ffmpeg (only `ffprobe` on
  tiny files at upload). `PIPE` runs it for real. A scripted fake binary
  (`FFMPEG_BIN` pointing at a shell script that sleeps or exits non-zero)
  simulates timeouts and encoder errors.
- **Storage.** `LocalStorage` on a pytest temp dir. A `FaultyStorage` wrapper
  injects `StorageFull` and delete failures on chosen calls.
- **Time.** `FakeClock` is injected everywhere (`clock.py`). No test sleeps for
  backoff, windows, or retention; they advance the clock.
- **Rate limits.** Real `InMemorySlidingWindow` with `FakeClock`. The Q&A
  limiter reads `qa_log` for real.
- **Frontend.** `MockTransport` (the same one used by mock mode) plus a
  `FakeVideo` class that emits scripted `timeupdate`, `seeking`, and `ended`
  events.
- **Not mocked:** the database, the state machines, the permission checks,
  `ConfirmPolicy`, the media access rules. Tests for guards use the real stack.

### 1.3 Conventions

- Case IDs: `<level>-<area>-<nn>`. An ID never changes after merge; a removed
  case is marked "retired", not renumbered.
- Each case lists PRD IDs or data model invariants (`I-n`) it covers. A case
  with no PRD ID covers an invariant or an architecture rule.
- Expected results quote error `code` values from `01-api-spec.md`. Tests
  assert `code`, never `message`.
- API guard tests are parameterized over (role, ownership, state) tables so a
  missing guard fails one named row.
- A guard test always includes the allowed row next to the denied rows.
- The suite fails if any `code` in the 01 catalog is never asserted
  (meta-test `UT-META-01`).
- Property tests (hypothesis): public fact visibility (`I-1`), coverage vs
  not-observed (`PUB-4`), range snapping bounds (`I-3`), alias filtering (`I-16`).

### 2.4 Eval data (outside `tests/`, versioned)

- `eval/spike_labels.jsonl`: 10 real clips (hand-labeled behavior intervals:
  `{clip, situation, behavior, start_s, end_s}`; 5 or more with English or
  Korean narration). Clips are not committed if they show people; the file
  lists where they live (verify).
- `eval/qa_adversarial.jsonl`: the QA-7 set. It is defined once, in
  `04-ai-design.md` section 10.2 (fixture dog "Biscuit" with 10 confirmed facts
  F1-F10, six categories, 74 cases: `no_evidence` 20, `paraphrased_trait` 12,
  `child_safety` 10, `health` 10, `injection` 12, `answerable` 10; each line
  `{id, category, question, expect, allowed_facts, notes}`). This file does not
  repeat the cases, the counts or the pass bars. `SAFE-META-01` asserts that the
  JSONL matches the 04 section 10.2 counts and ID list.

## 6. Definition of done for R1

checked by the CI pipeline; items 9 to 14 are checked once per release by a
person and recorded in `eval/results/release-<date>.md`.

1. `UT`, `DB`, `API`, `FE` suites pass on a clean checkout: zero failures,
   zero skipped cases except `photo.heic` where the decoder is absent.

   that will be deployed), including `PIPE-RETRY-*` and `PIPE-DEL-*`.

4. `SAFE-A-*` passes: 0 rendered facts outside the dog's confirmed set under
   the scripted attacker; every response text traces to a fact or a template.

   `security/`; 100 percent branch coverage of `ConfirmPolicy` and
   `MediaAccessService`.
8. No test relies on a real provider, real clock, or network (except `SPIKE`,
   `SAFE-L`, `E2E`).

   range accuracy (hand-checked, Wilson interval printed); otherwise `DRAFT_MODE=segments` is set and
   `SPIKE-TS-02` shows at least 80 percent. The chosen mode and numbers are
   recorded (ADR-0029 follow-up).
