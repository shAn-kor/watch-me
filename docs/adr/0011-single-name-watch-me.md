# ADR-0011: One name, "Watch Me!", for both markets

- Status: Accepted
- Date: 2026-10-28

## Context

- SERVICE.md line 3 (decided 2026-10-28): the dog's voice, "Rescue Me!" style; one name for both markets; no Korean name.
- The name fits the product: the viewer watches the clip evidence.
- Name collisions and trademark in the pet/adoption space are unchecked (SERVICE.md section 13).

## Decision

Use "Watch Me!" in the product, UI and repository (`watch-me/`) for both US and Korea. No separate Korean name.

## Alternatives considered

- A separate Korean name: rejected by decision; reasoning beyond "one name" is not recorded in the inputs.
- Other English names: not recorded in the inputs.

## Consequences

- Positive: one brand across the Korea-to-US flow.
- Negative: trademark and App Store collisions unknown; the Korean market may find an English name harder (unverified).
- Follow-up: check App Store, USPTO, KIPRIS before public launch (PRD section 9).
